# Hello Island · v0.2 확장 기획 패키지

6세 시작 아이패드 영어 듣기·단어 수집 게임의 기획·어휘·맵 설정 파일입니다.

## 구성 파일

- `plan.md` — 6→7→8세 맵 이동, 카드/오답 큐, 영어 듣기, 도감 캐릭터, iPad PWA 구현·QA 기준.
- `vocabulary.seed.json` — **395개** 단어: 기존 6세 155개(원래 ID 유지), 7세 신규 120개, 8세 신규 120개. 단어 자체의 수집 캐릭터 정의 포함.
- `stages.seed.json` — **큰 맵 3개·세부 구역 22개**, 100% 수집 후 20문제 관문, 7/8세 구역당 80% 순차 해금, 이전 단계 복습 비율.
- `wordlist-by-age.md` — 신규 240개 단어를 한국어 뜻과 함께 구역별로 보기 위한 표.
- `validate_hello_island_data.py` — 데이터 무결성 검사 실행 스크립트(표준 Python만 사용).

## 검증 실행

```bash
python validate_hello_island_data.py
```

## 꼭 구별할 점

- **계획/데이터이지 실행 가능한 게임 전체 소스가 아닙니다.**
- 이미지·실제 영어 발음 오디오·애니메이션 파일은 동봉되어 있지 않습니다. 파일 경로는 제작용 플레이스홀더입니다. `content_status=seed_only` 단어는 실제 문제 출제 금지.
- 6/7/8세는 게임 난이도 레벨명입니다. Cambridge/British Council 주제를 참조해 개별 선별했으며 그 기관의 공식 나이별 필수어휘 목록이 아닙니다.
- 아이에게 보여주는 수집 캐릭터는 반드시 **그 영어 단어의 대상**이어야 합니다. 고양이는 고양이, 물고기는 물고기, 버스는 버스; 행동은 그 행동을 보여주는 짧은 장면으로 표현합니다.
- 보호자 설정에서 연령 단계·새 단어 유입 속도·구역 잠금을 조정할 수 있게 구현하세요.

## MVP 개발 권장 순서

1. `plan.md`의 MVP 0 규칙으로 15단어 샘플 게임과 음성/이미지 동작부터 확인
2. `vocabulary.seed.json`과 `stages.seed.json`으로 맵 상태/도감/단어 수집 엔진 연결
3. 기존 6세 단어 이미지·음성을 제작해 155개를 채우고, 완주 관문 및 7세 해금 검증
4. 7세 120개·8세 120개 콘텐츠/음성을 검수해 순서대로 공개
