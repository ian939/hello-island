# Hello Island — 6~8세 단계형 영어 단어 수집 탐험 게임
> **개발용 기획서 / `plan.md` v0.2**  
> 작성: 2026-10-18  
> 플랫폼: iPad 우선 터치 웹앱(PWA) · 모바일/태블릿 확장 가능  
> 기획 상태: 6·7·8세 단계별 단어 395개 및 맵 해금·도감 캐릭터 규칙 반영 / 그림·오디오 에셋은 별도 제작

## 0. 프로젝트 한 줄 정의

**하루 30·50·100개의 그림-영어 선택 문제를 풀고, 틀린 카드는 뒤로 돌아가며, 모든 카드를 정답 처리해야 탐험이 완료되는 영어 듣기·어휘 수집 게임. 6세·7세·8세의 세 가지 큰 맵은 이전 맵 도감 완성 후 차례로 열리고, 수집하는 캐릭터는 바로 그 단어 자체다.**

정답을 맞히는 동안 단어 소리를 자연스럽게 반복해서 듣고, 처음 발견한 단어는 섬별 도감에 모인다. 단어의 실제 숙달 여부는 그날의 마지막 정답이 아니라 **다른 날에도 스스로 다시 맞히는지**로 판단한다.

### 핵심 원칙(변경 불가)

1. 보호자가 그날의 목표를 **30 / 50 / 100문제** 중 선택할 수 있다.
2. 왼쪽에 크고 명확한 그림(또는 학습에 적합한 이모지), 오른쪽에 영어 단어 보기와 각각의 듣기 버튼을 둔다.
3. **정답 카드는 완료**하고 **오답 카드는 뒤로 재배치**한다. 모든 목표 카드를 정답 처리해야 해당 탐험이 끝난다.
4. **문제 수 = 세션 시작 때 생성한 목표 카드 수**다. 오답 재도전은 추가 출제이므로 실제 답변 횟수는 선택한 수보다 늘 수 있다.
5. 아이는 영어 철자를 몰라도 **그림과 발음을 연결**해 진행할 수 있어야 한다.
6. 진행 중 여러 번 자연스러운 영어 발음을 듣는다. **소리는 학습의 중심**이며 효과음·BGM보다 우선한다.
7. 아이의 오답은 실패/벌칙이 아니다. 실수 후 다시 만나게 하되, 정답을 알려주는 도움 장치를 둔다.
8. 정답 보상은 **도감·탐험·꾸미기**로 연결한다. 무작위 과금형 뽑기, 광고, 순위 경쟁은 배제한다.
9. **6세 155개 → 7세 신규 120개 → 8세 신규 120개**, 총 395개 단어를 3단계 맵에 배치한다. 이전 단계 전체 도감과 마지막 복습 미션을 완료해야 다음 큰 맵으로 이동한다.
10. **수집 대상은 해당 영어 단어 자체**다. `cat`=고양이, `fish`=물고기, `bus`=버스. 별도의 랜덤 몬스터로 바꿔 보여주지 않는다.
11. 6·7·8은 **게임의 레벨 이름**으로, 실제 나이의 필수 교과 단어라고 주장하지 않는다. 아이의 진행이 빠르거나 느리면 보호자가 단계를 조정할 수 있다.

## 1. 문제 정의 / 목표 대상

### 사용자
- **주 사용자:** 6세부터 시작하는 영어 입문 아이. `cat`, `dog` 같은 동물 단어는 일부 알지만 새로운 단어·철자 읽기는 아직 어려울 수 있다. 7세·8세 맵으로 진도 확장해도 듣기 중심을 유지한다.
- **보조 사용자:** 보호자. 목표 문제 수 선택, 아이가 아는 단어 체크, 학습 이력 확인, 난이도 설정 담당.
- **기기:** iPad 가로 방향을 우선하되 세로 방향에서도 이용 가능하도록 반응형 구현.

### 세 가지 성공 목표
- **어휘:** 그림과 음성을 연결하고, 다른 날에도 같은 단어를 구분할 수 있다. 6→7→8 맵의 새 단어가 기존 단어를 밀어내지 않도록 나선형 복습한다.
- **듣기:** 한 세션에서 단어와 짧은 자연스러운 영어 표현을 여러 번 듣는다.
- **몰입:** 아이가 “공부를 끝내자”보다 “도감의 다음 친구를 만나자”라고 느끼게 한다. 단어 캐릭터가 맵 안에서 실제로 움직이는 수집 경험을 제공한다.

### 반드시 피할 것
- 아직 읽지 못하는 아이에게 **영어 글자만 보고 정답을 고르도록 강제**하는 것.
- 오답을 들을 때마다 빨간 X, 큰 경고음, 점수 감점, 생명 차감 등 부정적 피드백을 주는 것.
- 100문제 선택 시 100문제를 **한 번에 끝낼 때까지 기기를 놓지 못하게** 하는 것.
- 답을 맞히고 도감에 등록했다는 이유만으로 “완벽하게 암기한 단어”로 간주하는 것.
- 이모지의 모양이 기기별로 달라져 학습 뜻이 애매해지는 상황을 방치하는 것.

## 2. 콘셉트와 세계관

### 가칭: **Hello Island / 헬로 탐험섬**

6세·7세·8세의 **세 가지 큰 월드(맵)**를 순서대로 여행한다. 6세의 기존 10개 작은 섬은 그대로 유지하고, 7세·8세에 각각 6개 새로운 구역을 추가한다. 정답을 맞히면 **그 단어 자체가 수집 캐릭터**가 되어 도감과 맵에 합류한다. 각 구역을 완성할수록 실제로 동물·먹거리·사물·장소가 늘어나 풍경이 채워진다.

| 6세 첫 탐험섬의 구역 | 대표 소재 | 예시 |
|---|---|---|
| 동물의 숲 | 친숙한 동물 → 확장 동물 | cat, dog, cow, duck, rabbit |
| 맛있는 마을 | 과일·먹거리 | apple, banana, milk, cake |
| 장난감 마을 | 탈것·놀이·사물 | car, train, robot, ball |
| 우리 몸 연구소 | 신체 부위 | hand, nose, mouth |
| 무지개 언덕 | 색깔 | red, blue, green |
| 숫자 별나라 | 수량 개념 | one, two, three |
| 반짝 자연섬 | 자연 | sun, moon, star |
| 생활 마을 | 옷·집 안 물건 | hat, shoes, door |
| 움직임 놀이터 | 행동 (확장 단계) | run, jump, swim |
| 표정과 크기 광장 | 감정·반대말 (확장 단계) | happy, sad, big, small |

### 6·7·8세 큰 맵 구조

| 단계 | 큰 맵 이름 | 신규 단어 | 세부 구역 | 해금 규칙 |
|---|---|---:|---|---|
| 6세 | 🌳 첫 탐험섬 | 기존 155 | 위 10개 구역 | 기본 시작 맵 |
| 7세 | 🏘️ 신나는 모험 마을 | 120 | 학교·집·시장·야생·도시·도형/숫자 (각 20) | 6세 155개 수집 + 20카드 복습 미션 완료 |
| 8세 | 🚀 별빛 대탐험 | 120 | 직업·장소·날씨/자연·동작·운동/음악·우주 (각 20) | 7세 120개 수집 + 20카드 복습 미션 완료 |
| **합계** | 3개 큰 맵 | **395** | 22개 하위 구역 | 진행 기록·수집 캐릭터 유지 |

> 7/8세 단어는 Cambridge Pre A1 Starters/A1 Movers 및 British Council LearnEnglish Kids의 주제 영역을 참고해 자체 선별했다. **공인된 연령별 필수 단어 목록은 아니다.** 8세 우주 구역은 흥미 확장용 테마를 포함하므로 보호자가 우선순위를 조절할 수 있다.

**보상 구성**
1. **발견 도감:** 어떤 단어든 처음 정답을 맞히면 **단어 자체의 수집 캐릭터**를 1회 해금한다. `cat`은 고양이, `fish`는 물고기, `apple`은 사과다.
2. **반짝 숙련 배지:** 같은 단어를 서로 다른 날짜에 독립적으로 맞힌 기록이 쌓이면 **해당 단어 캐릭터**에 반짝 프레임을 부여한다. 최초 수집과 구분한다.
3. **섬 꾸미기:** 10개의 *완료 카드*마다 별/조각 1개를 모으고, 완료한 조각으로 섬 배경을 꾸민다.
4. **소리 나는 도감:** 도감에서 **고양이/물고기/사과 등을 직접 터치**하면 해당 영어 발음과 짧은 표현이 나온다. 동물은 움직이고, 탈것은 굴러가며, 행동/상태 단어는 짧은 장면을 보여준다.
5. **매일의 엔딩:** 30·50·100 중 무엇을 선택했든 그날 목표를 마치면 동등한 축하 엔딩을 보여준다. 100문제가 더 좋은 아이처럼 보이지 않도록 한다.

> 아이가 좋아하는 수집형 게임 감각은 살리되, 특정 기존 IP의 캐릭터·로고·상표·디자인은 사용하지 않는다.

## 3. 하루 플레이 흐름

```text
홈 화면
  └─ 현재 큰 맵/구역 확인 (기본: 6세 / 이전 맵 재방문 가능)
      └─ 오늘의 탐험 선택 (30 / 50 / 100)
      └─ [처음 이용 시] 아는 단어 확인 / 관심 있는 섬 고르기 (보호자)
          └─ 오늘의 새 단어 미리 만나기 (짧은 소리·그림 소개)
              └─ 문제 1 → 그림 + 영어 보기 3개 + 듣기
                  ├─ 정답 → 칭찬 음성 → 카드 완료 → 도감 발견 → 다음 문제
                  └─ 오답 → 중립적 안내 + 듣기 도움 → 카드 뒤로 재배치
              └─ 10개 완료마다 짧은 보상·쉬어가기 화면
              └─ 모든 목표 카드 정답 완료
                  └─ 축하 애니메이션 → 오늘 수집한 단어 캐릭터 → 다음 탐험 예고
                      └─ 큰 맵 도감의 전 단어 수집 시 '마지막 복습 미션(20카드)' 개방
                          └─ 미션 20카드 모두 정답 완료 시 다음 큰 맵 포털 열림
                              └─ 새 맵 진입, 신규 구역과 새 단어 순차 개방
```

### 목표 문제 수 선택

| 오늘의 목표 | 새로 소개할 단어 수(초기 권장값) | 나머지 출제 | 중간 쉼표 |
|---|---:|---|---|
| 30문제 | 최대 5개 | 이미 만난 단어 복습·반복 | 10문제마다 |
| 50문제 | 최대 7개 | 이미 만난 단어 복습·반복 | 10문제마다 |
| 100문제 | 최대 10개 | 이미 만난 단어 복습·반복 | 10문제마다 |

- 표의 수치는 **초기 기획 설정**이며 실제 아이의 반응에 맞춰 조절한다. 30문제 = 30개의 새로운 단어가 아니다.
- **30문제 기본 권장**. 50/100문제도 허용하지만, 잠시 멈추고 이어 할 수 있도록 한다.
- 일시정지·앱 종료·잠금 뒤 재진입 시 **남은 카드와 오답 큐를 그대로 복원**한다.
- 자정이 지나 미완료 세션이 있으면 `하던 탐험 이어하기`를 기본으로 표시하고, 보호자가 `새로 시작`을 선택한 경우에만 이전 세션을 미완료로 보관한다.
- 도중에 30→50으로 목표를 늘릴 경우, 보호자 설정에서 기존 완료 30개를 유지하고 **20개만 추가**한다. 줄이기는 미완료 카드 수 기준으로 보호자 확인 후 처리한다.

## 4. 단일 문제 UX (MVP의 가장 중요한 화면)

### 레이아웃

```text
┌─────────────────────────────────────────────────────────────┐
│ 동물의 숲 🌲                        탐험 진행  12 / 30     │
│ ━━━━━━━━━━━━━━━━━━━                                        │
│                                                             │
│  ┌──────────────────────────┐   ┌─────────────────────────┐ │
│  │                          │   │ 🔊 DOG                  │ │
│  │                          │   ├─────────────────────────┤ │
│  │         큰 고양이 그림      │   │ 🔊 CAT     ◀ 미리 듣기  │ │
│  │                          │   ├─────────────────────────┤ │
│  │         ♬ 듣기 도움        │   │ 🔊 COW                  │ │
│  │                          │   └─────────────────────────┘ │
│  └──────────────────────────┘       [ 이거야! ]            │
│                                                             │
│  🌟🌟🌟     🔊 다시 듣기            ⏸ 잠시 쉬기            │
└─────────────────────────────────────────────────────────────┘
```

### **기본 모드: 듣고 고르기** (6세 영어 입문)

- 왼쪽: 대상 사물을 정확하게 알아볼 수 있는 일러스트. 이미지의 글자·레이블은 노출하지 않음.
- 오른쪽: 3개 영어 보기(`DOG`, `CAT`, `COW`). 각 카드에 듣기 아이콘.
- 아이가 보기 카드를 **처음 탭하면 그 보기의 영어 발음이 재생되고 선택 표시**가 된다.
- `이거야!` 버튼을 누르거나 같은 카드를 재차 탭하면 정답 제출.
- 다른 카드를 터치하면 그 단어를 들어보고 선택을 변경할 수 있다.
- 기본 음성 안내: 짧고 친숙한 영어 (`What's this?`, `Listen and choose!` 등). 매 문항 같은 문장을 길게 반복하지 않는다.
- 왼쪽 `도움 듣기`는 정답 단어를 직접 발음한다. **누르면 힌트 사용 기록**을 남기고, 해당 시도의 숙련 판정은 보수적으로 처리한다.
- **중요:** 모든 문항에서 정답 단어를 시작부터 자동 재생하면 아이가 그림 뜻을 몰라도 *방금 들은 소리와 같은 보기*만 찾을 수 있다. 따라서 기본 모드는 보기별 발음을 들어 **그림과 소리를 연결**하게 한다.

### 익숙해진 뒤 선택 가능한 모드
- **빠르게 고르기:** 보기 한 번 탭으로 음성 재생 + 정답 제출. 이미 익힌 단어용.
- **소리 따라 찾기:** 목표 단어를 먼저 듣고 맞는 영어 글자를 고르는 모드. 듣기-철자 연결 연습용.
- **추후 확장:** 영어를 듣고 그림 3개 중 하나를 고르는 반대 방향 문제, 간단한 듣기 미션.

### 정답 피드백
- 문제 정답 `cat`일 때: 밝은 효과 + `Cat! It's a cat!` 자연스러운 영어 발음.
- 첫 수집 단어이면 정답 대상(`cat`이면 고양이 자체)이 화면 구석에서 나타나 도감으로 들어간다.
- 설명 화면은 짧게(예: 0.8~1.5초) 표시하고 아이가 원하면 탭해 바로 진행한다.
- 정답 단어의 발음을 **선택 미리 듣기 + 정답 음성(단어/짧은 문장)**으로 다시 노출.

### 오답 피드백
- 선택 단어 발음은 그대로 들려주되, 빨간 경고 대신 `다음에 다시 만나자!` 정도의 조용한 시각 안내.
- 정답 단어의 이미지와 발음을 추가로 들려주는 도움을 제공할 수 있다.
- 현재 카드의 완료 처리는 하지 않는다. **4~7개의 카드 뒤**에 재삽입하는 것을 목표로 하며, 큐가 짧으면 가능한 가장 뒤에 둔다.
- 같은 단어를 두 번 이상 틀리면 보기 1개를 줄이거나, 정답 그림을 더 명확하게 보여주고, 올바른 단어 음성을 들려준다.
- 세 번째 오답부터는 **시각 힌트 + 음성 듣기**를 제공하되 정답 선택 동작은 아이가 직접 하도록 한다.
- 정답을 맞혀야 그 카드가 완료된다. 틀렸던 이력은 유지하되 점수 차감은 없다.

### 발음 노출 설계
1. 새 단어 첫 도입: **그림과 함께 단어를 2회** 듣는다.
2. 문제 진행: 아이가 관심 있는 **보기 단어들을 터치해 발음**을 듣는다.
3. 정답 후: **단어 1회 + 간단한 문장 1회** 듣는다.
4. 도감: 수집한 단어를 다시 눌러 **언제든 복습**한다.
5. 화면 전환 효과음은 작은 볼륨, 영어 음성이 재생될 땐 배경음 자동 감소(ducking).
6. 소리가 겹치면 현재 음성 재생을 정리하고 다음 음성을 재생한다. 빠른 연타도 안전하게 처리한다.
7. 학습용 음성은 **같은 억양(en-US 기본)**과 일정한 품질을 유지한다. 느린 듣기(예: 0.85~0.9배)와 일반 듣기를 제공한다.

## 5. 문제 큐/오답 재배치 규칙

### 핵심 데이터 구조

```ts
type QuizCard = {
  cardId: string;           // 같은 단어가 반복 출제되어도 고유
  wordId: string;
  optionWordIds: string[];  // 정답 1 + 오답 2 (확장: 오답 3)
  attempts: number;
  hintsUsed: number;
  firstAttemptCorrect: boolean | null;
};

type Session = {
  id: string;
  stageId: "age6" | "age7" | "age8";
  currentZoneId: string | null;
  localDate: string;
  targetCount: 30 | 50 | 100;
  completedCount: number;
  cards: QuizCard[];
  pendingQueueCardIds: string[];
  currentCardId: string | null;
  status: "intro" | "playing" | "break" | "paused" | "completed";
};
```

### 의사코드

```ts
function submit(card: QuizCard, chosenWordId: string) {
  card.attempts += 1;

  if (card.attempts === 1) {
    card.firstAttemptCorrect = chosenWordId === card.wordId;
  }

  if (chosenWordId === card.wordId) {
    markCardDone(card.cardId);
    updateWordProgress(card.wordId, card.attempts, card.hintsUsed);
    unlockDiscoveryIfFirstCorrect(card.wordId);
    if (completedCount === targetCount) finishMission();
    else if (completedCount % 10 === 0) showBreakScreen();
    else showNextCard();
  } else {
    showGentleFeedback(card.wordId);
    const offset = Math.min(randomInteger(4, 7), pendingQueueCardIds.length);
    pendingQueueCardIds.splice(offset, 0, card.cardId);
    persist();
    showNextCard();
  }
}
```

### 큐 구성 및 예외
- 시작 시 **정확히 N개 QuizCard**를 생성하며, 단어는 한 세션에서 여러 카드에 재사용할 수 있다.
- 완주 조건은 `completedCount === targetCount && pendingQueue.length === 0 && currentCard가 완료됨`.
- 정답 완료 카드는 **다시 오답 큐에 넣지 않는다**. 다만 다른 `cardId`로 처음부터 계획된 복습 카드가 있을 수 있다.
- 가능한 경우 같은 `wordId`가 **3문제 이내 연속 반복되지 않도록** 카드 순서를 섞는다.
- 오답 큐 삽입 시 현재/다음 문제와 같은 단어가 겹치면 다른 유효한 위치로 조정한다.
- 마지막 남은 1문제를 틀렸다면 다른 문제가 없으므로 바로 다시 제시하되, 오답 듣기 도움을 제공한다. 아이를 영구적으로 막는 상태를 만들지 않는다.
- 새로고침/앱 종료 사이에서 정답·오답 입력을 **원자적으로 저장**하고, 저장이 끝난 상태로 복원한다.
- 문항 옵션은 정답 1개만 포함. 동일 표기, 중의어, 혼동되는 그림·용례는 보기로 생성하지 않는다.

## 6. 6→7→8세 확장형 단어 커리큘럼

### 콘텐츠 정책
- 아이가 이미 어느 정도 안다고 가정할 수 있는 동물·음식·탈것에서 시작해 **성공 경험**을 만든다.
- “쉬운 단어”는 **철자가 짧은 단어**만 뜻하지 않는다. 그림으로 즉시 구별 가능하고, 생활에 자주 등장하며, 영어 발음과 의미가 명료한 단어를 우선한다.
- **단어 등급과 아이의 실제 친숙도는 별개**다. 처음 시작할 때 보호자가 익숙한 단어를 체크할 수 있어야 한다.
- 영어·한국어의 1:1 대응이 모호한 단어는 그림 장면과 뜻을 고정한다. 예: `orange`(과일)와 `orange`(색깔)는 서로 다른 `wordId`.
- 감정·행동·위치 개념은 이모지 한 개로 시험하지 않고, 직접 제작한 **행동 장면 일러스트**가 완성된 뒤 활성화한다.
- 색깔은 글자가 들어가지 않은 색상 칩, 숫자는 숫자 글씨가 아닌 **물건 개수**를 이미지로 제시한다.
- **6세 기존 155개(Tier 0=68, Tier 1=63, Tier 2=24)는 원래 ID를 유지**한다. 7세 신규 120개, 8세 신규 120개를 덧붙여 **총 395개**를 `vocabulary.seed.json`에 저장한다.
- **`tier`와 `stage_id`를 구분**한다. `tier`는 기존 6세 목록 내 쉬움/확장/장면 난이도 정보와 호환하기 위한 필드이며, `stage_id`(`age6`/`age7`/`age8`)가 큰 맵 소속을 결정한다.
- **7세 구역별 단어:** 학교 20, 집 20, 시장·음식 20, 바다/야생 20, 도시/교통 20, 도형·숫자 20.
- **8세 구역별 단어:** 직업 20, 공간·장소 20, 날씨·자연 20, 행동·일과 20, 스포츠·음악 20, 우주 20.
- 7세 전체 단어와 8세 전체 단어의 뜻은 `wordlist-by-age.md` 참고. `stages.seed.json`은 단계·구역·해금 조건의 데이터 원본이다.
- 단어 시드는 **음성·일러스트 실파일을 포함하지 않는다**. 파일 경로는 구현용 예시이며, 출시 전에 실제 에셋 제작·검수가 필요하다. 수집 캐릭터의 움직임은 CSS/Lottie/스프라이트 등을 사용해 구현하되 오프라인에서도 동작해야 한다.

### 단계 정의

| 단계 | 아동의 경험 | 보기 구성 | 단어/콘텐츠 |
|---|---|---|---|
| Tier 0 | 이미 아는 세계에서 탐험 시작 | 3지선다 + 듣기 | 동물, 과일, 탈것, 기본 색/수 |
| Tier 1 | 모르는 단어 조금씩 추가 | 기본 3지선다, 적응 후 4지 | 확장 동물, 생활 물건, 몸 |
| Tier 2 | 장면·동작·상태까지 확대 | 3~4지 + 선명한 장면 | run, swim, happy, big 등 |
| 7세 맵 | 6세 맵 도감 완성 후 진입 | 먼저 3지선다, 익숙해지면 4지선다 | school, dolphin, bus, circle, eleven 등 신규 120개 |
| 8세 맵 | 7세 맵 도감 완성 후 진입 | 3~4지 + 행동/장면 일러스트 | doctor, wake up, volcano, rocket 등 신규 120개 |
| 추후 | 소리만 듣고 그림/문장 선택 | 다양한 게임 규칙 | 일상 표현, 짧은 문장 |

### 단계/진도 정책
- 실제 나이로 맵을 자동 변경하지 않는다. **이전 큰 맵을 모두 수집하여 완성할 때** 다음 단계 포털이 열리는 게임 규칙이다.
- 6세에서 7세로 넘어가도 익힌 6세 단어는 사라지지 않는다. 7세 문제에 6세 단어 복습을, 8세 문제에 6·7세 복습을 섞는다.
- 7세·8세의 각 하위 구역은 **직전 구역 단어 80%(20개 중 16개)** 수집 시 순차 개방한다. 단, 큰 맵에서 다음 큰 맵으로 넘어가려면 전체 100% 수집이 필요하다.
- 각 단어는 새로 만나기 → 처음 정답으로 수집 → 다른 날 재확인으로 숙련 배지 획득 순서다. **맵 해금과 숙련 배지는 별개의 목표**다.
- 콘텐츠가 아직 그림/음성 없이 준비 중이라면 해금 분모에서 임의로 빼서 조기 졸업시키지 않는다. 각 큰 맵의 명시된 전체 단어(155/120/120)가 공개 가능해야 최종 게이트가 활성화된다.

### 초기 15개 파일럿 단어
`cat, dog, cow, pig, duck, fish, apple, banana, strawberry, car, ball, red, blue, sun, star`

처음 5~10문제는 이미 아는 동물 위주로 구성해 아이의 조작 이해와 자신감을 높이고, 이후 보호자가 체크한 **아직 모르는 단어 3~5개**를 미리 듣기와 함께 도입한다.

## 7. 개인화 및 반복 학습

### 단어별 상태

```ts
type WordProgress = {
  wordId: string;
  introducedAt: string | null;
  discoveredAt: string | null;
  encounteredCount: number;
  firstTryCorrectCount: number;
  wrongCount: number;
  hintUsedCount: number;
  distinctCorrectDates: string[];
  recentAttempts: Array<{
    date: string;
    firstTryCorrect: boolean;
    hinted: boolean;
  }>;
  dueDate: string | null;
  status: "unseen" | "learning" | "reviewing" | "mastered";
};
```

### 임시 복습 로직(추후 실제 사용 결과로 조절)
- 신규 단어: 소개 후 **당일 최소 2번 정도** 다른 카드로 만나도록 후보 슬롯에 반영한다.
- 첫 시도 오답 또는 힌트 사용: 해당 세션 뒤에서 재도전, 다음 날에도 우선 출제.
- 첫 시도 정답: 다음 날 재등장 후보.
- 날짜가 달라져도 자력 정답이 이어지는 단어: 출제 간격을 점진적으로 늘림(예: **1 → 3 → 7 → 14일**).
- **숙달(`mastered`) 예시 기준:** 서로 다른 **3일 이상** 도움 없이 정답, 최근 3회 중 2회 이상 첫 시도 정답. 한 번의 세션에서 여러 번 맞혔다고 숙달 처리하지 않는다.
- 숙달 이후 오답이 늘면 복습 간격을 단축하며 도감 스티커는 **회수하지 않는다**.

### 매일의 문제 선별 우선순위
1. 오늘 소개한 신규 단어(설정한 상한 이내).
2. 복습일이 도래했거나 최근 틀린 단어.
3. 익숙하지만 최근 만나지 않은 단어.
4. 아이가 관심 있는 섬의 단어.
5. 반복 다양성을 위한 기존 숙달 단어.

**단계별 기본 출제 비율(초기 제안, 부모 설정 조정 가능)**
- 6세 맵: 6세 단어 100%.
- 7세 맵: **현재 단계 70% + 6세 복습 30%**.
- 8세 맵: **현재 단계 70% + 7세 복습 20% + 6세 복습 10%**.
- 30/50/100은 **목표 카드 수**이며, 새 단어 개수와 무관하다. 하루 신규 소개 상한은 단계별 5/7/10개를 기본으로 한다.
- 복습 비율에 의해 과거 단계 단어가 반복돼도 현재 단계 도감 카운트로 다시 합산하지 않는다. `wordId`별 최초 수집은 오직 한 번.

**피해야 할 조합:** 정답과 오답 단어가 발음·그림·범주상 거의 구분 안 되는 경우, 정답이 늘 같은 버튼 위치에 나타나는 경우, 실제 그림이 둘 이상의 선택지를 동시에 표현하는 경우.

### 최초 시작의 “아는 단어” 설정
- 선택적 보호자 설정: “아이가 이미 익숙한 동물·사물” 체크.
- 모를 경우 **직접 입문용 10문제**로 관찰하고 그 결과를 참고하되 1회 실수로 미숙련 확정 금지.
- 보호자는 개별 단어를 `이미 앎 / 소개 필요 / 당분간 제외`로 설정할 수 있다.
- **아이가 플레이하는 화면에 한국어 단어 정답을 노출하지 않는다.** 한국어 뜻은 보호자 도감 관리에서만 보인다.

## 8. 재미 요소 설계

### 꼭 넣을 재미 4개(MVP)
1. **한 카드 정답 = 탐험 캐릭터 1걸음:** 진행이 눈으로 보인다.
2. **처음 맞힌 단어 = 단어 캐릭터 수집:** `cat`은 고양이 자체가 나타나 도감의 집에서 꼬리를 흔들고, `fish`는 물고기 자체가 수조에서 헤엄친다. 한 단어당 한 캐릭터/장면만 영구 수집한다.
3. **10개 완료 = 짧은 섬 꾸미기:** 작은 별/조각을 받아 배경에 붙이는 행동 1회. `계속하기 / 쉬기` 선택.
4. **목표 완주 = 그날의 작은 엔딩:** 도감에 새로 등록된 단어 캐릭터를 펼쳐 보여주고 축하 영어 음성을 제공한다.

### 추가 아이디어(후속 단계)
- **숨은 친구 찾기:** 섬 그림에서 오늘 배운 단어의 작은 그림을 찾는다.
- **단어 캐릭터 상호작용:** 동물·과일·탈것을 터치하면 해당 단어 발음과 작은 움직임을 제공. 다른 몬스터를 소환하지 않음.
- **큰 맵 포털:** 6세/7세 맵 수집을 끝내면 다음 지도로 떠나는 짧은 컷신. 축하만 크게 하고 강제로 장시간 플레이하게 하지 않는다.
- **미니 보스:** 10문제마다, 이미 학습한 단어를 이용해 `Find the red ball`과 같은 듣기 미션. 타이머와 패널티는 없음.
- **하루의 세 문장:** 배운 단어로 자연스러운 짧은 문장을 3개 듣고 애니메이션 감상(선택 사항).

### 장시간 플레이 피로 방지
- 매 10개 완료 시 쉬어가기 화면 제공. 자동 다음 스테이지로 몰아가지 않음.
- 모든 상태 자동 저장. 50/100을 선택해도 **나눠서 완료** 가능.
- 플레이 시간이 아닌 **정답 학습·다음 날 회상**을 보상 중심으로 둔다.
- 반복할수록 너무 화려한 애니메이션이 나오지 않도록 모션 축소 옵션을 둔다.

| S05 | 10문제 휴식 | 오늘 모은 별/꾸미기, 쉬기/계속하기 | 필수 |
| S06 | 미션 완료 | 축하, 발견한 단어 캐릭터, 도감 이동 | 필수 |
| S07 | 단어 도감 | 섬별 잠금/발견/숙달 표시, 음성 반복 | 필수 |
| S08 | 보호자 모드 | 목표/단어/발음/진행 현황/초기화/백업 | 필수 |
| S09 | 선택 미니게임 | 숨은 친구, 문장 듣기 등 | 후속 |
| S10 | 큰 맵 지도 | 6·7·8세 맵의 잠금/해금, 현재 위치, 이전 맵 다시 방문 | 필수 |
| S11 | 맵 이동 컷신/포털 | 155개/120개 수집 후 20문제 복습 미션, 다음 맵 언락 | 필수 |
| S12 | 도감 상세 | `cat` 고양이 등 단어 그 자체의 움직임, 발음 재생, 숙련 배지 | 필수 |

### iPad UX
- 가로형을 기준으로 왼쪽 **그림 45~50% / 오른쪽 보기 50~55%** 비율.
- 아이의 손가락을 고려해 보기 터치 영역 **최소 64px 높이**를 목표로 한다.
- 페이지 전체 스크롤·문항 드래그·선택 텍스트 하이라이트를 게임 영역에서 막는다.
- 접근성 보조 기능을 무분별하게 차단하지 않으며, 앱 전체의 시스템 확대 기능 강제 차단에 의존하지 않는다.
- 아이가 원치 않게 나가기 어렵도록 홈 화면 추가(PWA) 사용을 고려하며, 필요하면 보호자가 OS의 `사용법 유도(Guided Access)` 기능을 활성화한다.
- 볼륨/음소거·다시 듣기·중단하기 버튼은 항상 보인다.
- 정답·오답을 색깔만으로 구분하지 않고 아이콘과 움직임/음성으로도 전달한다.

## 10. 기술 설계 (개발 기본안)

### 권장 방식
- **앱 형태:** 설치형처럼 이용 가능한 **오프라인 우선 PWA**. 최초 다운로드/업데이트를 제외하면 별도 서버·로그인 없이 학습 가능하도록 설계.
- **UI:** React + TypeScript + Vite (혹은 동급 경량 스택).
- **로컬 데이터:** IndexedDB에 사용자 단어 상태/세션 큐/설정을 영구 보관. 단순 설정은 localStorage도 가능.
- **오프라인 자산:** Service Worker / Cache API로 HTML·JS·CSS·그림·영어 오디오 파일 사전 캐시.
- **오디오:** 정해진 영어 단어·문구의 **검수된 MP3/M4A 사전 제작 파일**을 우선 사용. 실제 아이 기기에서 음질·발음·오프라인 재생 검증.
- **TTS fallback:** 브라우저의 `speechSynthesis`는 시제품/부족한 파일에만 보조적으로 사용. 기기별 설치 음성 차이 때문에 정식 음성 품질을 보장하는 유일한 수단으로 삼지 않음.
- **정답 생성:** 로컬 콘텐츠 JSON 기반. 모든 오답 선택지도 로컬 어휘 풀에서 선택.
- **외부 API:** MVP의 게임 플레이·학습·통계 동작에 필수로 사용하지 않음.
- **개인정보:** 이름, 마이크, 카메라, 위치, 클라우드 계정 불필요. 보호자 전용 백업/복원 JSON 기능은 후속 또는 MVP 후반.

### iPad 오디오 주의사항
- iPad Safari에서 사용자 동작 없는 오디오 자동 재생이 제한될 수 있다.
- **`탐험 시작` 버튼의 실제 터치 이벤트에서 오디오 세션을 초기화/활성화**하고, 이후 재생 가능 상태를 관리한다.
- `play()` 실패 또는 `AudioContext` 정지 시 무음으로 넘어가지 않고, 명확한 **`눌러서 소리 켜기`** 버튼을 보여준다.
- 화면 백그라운드→복귀, 음소거 스위치, 이어폰 연결, 다른 앱 오디오 간섭 등에서 동작 테스트.
- 음성 파일이 없는 단어는 조용히 출제하지 말고 **콘텐츠 미준비로 출제 제외**한다.
- 사전 제작 오디오 파일 저작권/사용권, 그림 자산의 사용권을 출시 전에 확인한다.

## 11. 콘텐츠 데이터 계약

파일: **`vocabulary.seed.json`** (총 **395개 단어**) + **`stages.seed.json`** (3개 큰 맵, 22개 구역, 포털 규칙) + **`wordlist-by-age.md`** (7/8세 신규 단어 전체 목록). 이미지·오디오·애니메이션 실파일은 포함하지 않는다.

```json
{
  "id": "animals-cat",
  "en": "cat",
  "ko_parent_only": "고양이",
  "world": "animals",
  "world_ko": "동물의 숲",
  "tier": 0,
  "stage_id": "age6",
  "zone_id": "age6-animals",
  "emoji_prototype": "🐱",
  "visual_type": "illustration_preferred",
  "audio_word_asset": "audio/en-US/cat.mp3",
  "art_asset": "images/animals/cat.webp",
  "collectible": {
    "id": "animals-cat",
    "kind": "word_subject",
    "subject_en": "cat",
    "art_asset": "images/animals/cat.webp",
    "animation": "tail_wag_and_blink"
  },
  "content_status": "seed_only",
  "asset_note": "예시 경로(파일은 별도 제작 필요)"
}
```

### 단계 해금 데이터 예시 (`stages.seed.json`)

```json
{
  "age7": {
    "kind": "previous_stage_completed",
    "previous_stage_id": "age6",
    "requires_all_collectibles": true,
    "final_review_card_count": 20,
    "final_review_completion_rule": "all_cards_eventually_correct"
  }
}
```

위 코드는 해금 정책 발췌 표현이며, **전체 3단계 데이터와 각 구역 규칙은 실제 `stages.seed.json`을 단일 진실원(Single Source of Truth)으로 사용**한다. 단계 해금 판정에는 반드시 `stage_id`와 `zone_id`를 사용하고, 단어가 속한 구역을 문자열 접두사 추측으로 판단하지 않는다.

### 콘텐츠 QA 기준
1. 영어 단어, 한글 뜻, 그림이 정확하게 대응하는가?
2. 발음이 일정하고 분명한가? 미국식/영국식 혼용이 없는가?
3. 오답이 **동일 뜻**이거나 맞는 답으로 인정될 소지가 없는가?
4. 색, 수량, 신체·행동처럼 기존 이모지로 의미가 불명확한 단어는 실제 그림을 만들었는가?
5. 복합어(`ice cream`) 및 두 뜻을 가진 단어(`orange`)는 역할에 맞게 정의했는가?
6. 아이 화면에서 정답 그림 안에 **영어 글자/숫자 힌트**가 새겨져 있지 않은가?
7. 화면에서 발생하는 모든 영어 문장은 원어민 수준의 자연스러운 발음/문장으로 검수했는가?
8. 실제 오디오 파일이 없는 단어가 출제 풀에 들어가지 않는가?
9. 단어를 맞혔을 때 등장하는 캐릭터가 **별개의 몬스터가 아닌 그 단어 자체**인가?
10. 7/8세의 학교·병원·공원, 직업·행동·날씨 등 **장면으로만 구분 가능한 단어를 뭉뚱그린 이모지로 출제하지 않았는가?**
11. 7/8세 숫자 11~20은 `1️⃣` 같은 자릿수 이모지 대신 **정확한 개수의 사물 또는 배열 그림**을 사용했는가?
12. 오답 선택지를 만들 때 `scooter`의 킥보드 의미, `bank`의 은행 의미, `goal`의 골대 의미 등 **정한 단어 뜻을 유지**하는가?

### 시드 활용 원칙
- `emoji_prototype`은 빠른 내부 시연용이다. **출시 품질의 시각 정답 자료로 일괄 사용 금지**.
- `tier: 2`(행동·감정 등)는 처음부터 전부 활성화하지 않는다. 적절한 장면 그림과 음성 파일이 준비되면 개방.
- TTS 음성 생성은 가능하면 **사전 제작 후 번들링**하고 런타임 호출에 의존하지 않는다.
- `"gold"`/`"open"`/`"close"`처럼 장면 의미가 여러 개인 단어는 실제 시연 후 제외하거나 명확한 용례로 한정할 수 있다.

## 12. 보호자 화면 / 측정

### 아이에게 보여줄 지표
- 오늘의 완료 카드 `현재/목표` (틀린 것을 완료로 세지 않음).
- 오늘 새로 데려온 **단어 캐릭터**.
- 도감 진행 및 섬 꾸미기 진행.
- 재도전 중인 문제를 **부정적으로 표시하지 않음**.

### 보호자에게 보여줄 지표
- **첫 시도 정답률:** 첫 번째 제출에서 정답인 카드 / 해당 세션에 최초 제출된 카드.
- **재도전 횟수:** 잘못 골라 큐에 되돌린 총횟수.
- **뜻-소리 익숙도:** 단어별 최근 시도, 다른 날짜 자력 정답, 힌트 사용 빈도.
- **새로 발견한 단어 수:** 처음 정답으로 등록된 고유 단어.
- **맵 해금 진행도:** 현재 단계 고유 단어 수집 수/전체(6세 155, 7세 120, 8세 120), 잠금/개방된 구역 수, 최종 복습 미션 여부.
- **숙련 단어 수:** 독립적인 다른 날짜 복습을 통과한 고유 단어.
- **음성 상호작용:** 단어 듣기 횟수/단어별 듣기 분포(선택적).
- 7일간 자주 틀린 단어 목록 및 추천 재학습 섬.

**주의:** 모든 카드를 결국 맞혀 끝나는 구조이므로 **최종 완료율 100%**는 학습 성취도 지표로 사용하지 않는다. 최초 정답률과 날짜를 달리한 자력 회상을 함께 본다.

## 14. 완료 조건(Acceptance Criteria)

1. 목표를 30으로 선택하고 **3번 틀렸을 때**, 카드가 사라지지 않으며 총 **30개 카드의 정답**으로만 완주한다.
2. 오답 카드가 **뒤의 다른 카드 다음에** 다시 출제된다. 남은 카드가 부족할 경우에도 멈추지 않는다.
3. 모든 선택지에서 **선택하기 전 그 단어를 소리로 미리 들을 수 있다**.
4. 글자를 잘 못 읽는 아이가 3개 보기를 듣고 그림의 뜻을 골라낼 수 있다.
5. 정답 직후 해당 단어와 짧은 영어 표현을 명확하게 다시 들려준다.
6. 같은 단어를 여러 번 출제해도 도감 **최초 해금은 1번만**, 숙련 판정은 날짜가 다를 때만 누적된다.
7. 아이가 중단하고 돌아와도 문제 수, 순서, 정답/오답 기록, 보상이 유지된다.
8. 오프라인 상태에서, 설치·캐시된 그림/음성을 사용하는 세션은 외부 API 없이 완주한다.
9. 6세 **155개를 전부 수집한 뒤** 마지막 복습 미션 20카드를 모두 정답 처리해야 7세 큰 맵이 열린다. 도중에 틀리면 재출제된다.
10. 7세 신규 120개 수집과 20카드 최종 복습을 마치면 8세 큰 맵이 열린다. 아직 안 푼 단어를 기존 복습으로 대체해 조기 해금하지 않는다.
11. 7세/8세 각각 **6개 구역 × 20단어**, 총 240개 신규 단어가 JSON 데이터에 존재하며 기존 155개 단어 ID는 변경되지 않는다.
12. 7세/8세의 첫 구역 외 다음 구역은 바로 앞 구역의 **16/20개**가 수집됐을 때 잠금 해제된다. 완료된 큰 맵/구역은 이후 복습에서 실수해도 다시 잠기지 않는다.
13. 수집 도감 `cat` = 고양이, `fish` = 물고기, `bus` = 버스가 실제로 표현된다. `run` 등 동작은 **동작 장면**을 수집한다.
14. 7/8세 세션에서 이전 맵 단어 복습이 섞여도 **새 단어 수집 카운트가 부정확하게 늘어나지 않는다.**
15. 그림/오디오가 아직 준비되지 않은 단어가 있다면 출제도 하지 않으며, 필수 콘텐츠 누락 상태에서 다음 단계 포털이 조기 활성화되지 않는다.
9. 초보 아이가 보기 카드를 터치하다 앱이 스크롤되거나 텍스트가 선택되는 일이 거의 없도록 설계한다.
10. 모든 활성화 단어의 그림·뜻·발음은 수동 QA를 통과한다.
11. `100문제` 선택 후 10문제만 하고 종료해도, **나머지 90개+오답 큐를 복원**해 이어 할 수 있다.
12. 정답률·발견수·숙련수는 서로 다르게 계산하고, 끝까지 풀어 최종 100%가 되었다고 숙련 100%로 표시하지 않는다.

### 자동화 테스트 우선순위
- queue: 정상 완료, 복수 오답, 마지막 문제 오답, 동일 단어 중복 카드, 30/50/100, 정답 1개 유지
- selection: 동일 단어 중복 보기·이미지 애매함·정답 위치 편향 방지
- persistence: 앱 종료 직전 오답/정답 이벤트 및 중복 보상 방지
- audio: 빠른 연속 탭, 이전 음성 취소, 자동 재생 실패, 무음 리커버리
- mastery: 하루 여러 번 정답 vs 서로 다른 날짜 정답 구별
- session: 자정 경과, 목표 상향, 미완료 보관, 오프라인 복원

## 18. 단계별 월드 이동과 완료 판정 (개발 필수 상세)

### '하루의 탐험 완주' vs '한 개의 큰 맵 완성'

- **하루 탐험 완주:** 선택한 30·50·100개 **카드**가 모두 정답 처리되어 `completedCount===targetCount`인 상태. 재도전 횟수는 제한 없음.
- **맵 도감 완성:** 그 단계에 속한 **서로 다른 고유 단어**가 모두 한 번 이상 정답으로 수집된 상태. 6세 155/155, 7세 120/120, 8세 120/120. 같은 단어 10회 정답을 10개로 세지 않는다.
- **마지막 복습 미션:** 이전 단계의 수집 단어에서 고르게 선택한 **20개의 서로 다른 단어**로 카드 20개를 만든다. 오답 카드는 보통 문제와 똑같이 큐 뒤에 재삽입하며 전부 최종 정답이 돼야 완료한다. 해당 미션의 첫 시도 정답률은 성취 지표로 따로 기록한다.
- **다음 큰 맵 개방:** 도감 완성 + 20카드 최종 미션 완료 + 콘텐츠/단계 데이터 검증. **성숙도(3일 자력 정답) 100%를 추가로 요구하지 않는다.** 숙련도는 다음 맵에서도 복습으로 계속 높인다.
- **부모 예외:** 자녀가 이미 더 높은 난이도를 소화하면 보호자 모드에서 다음 맵 수동 열기 가능. 아이 화면에는 '실패', '나이가 안 맞음'이라는 문구 금지.

### 해금/진행 상태 저장

```ts
type StageId = "age6" | "age7" | "age8";
type MapProgress = {
  currentStageId: StageId;
  unlockedStageIds: StageId[];
  unlockedZoneIds: string[];
  completedStageIds: StageId[];
  gateMissionStatusByStage: Record<StageId, "locked" | "ready" | "in_progress" | "completed">;
  gateMissionSessionIdByStage?: Partial<Record<StageId, string>>;
  manifestVersionAtCompletionByStage?: Partial<Record<StageId, string>>;
  parentUnlockedStages: StageId[];
};
```

### 개발 로직 의사코드

```ts
function isStageCollectionComplete(stageId: StageId, content: ContentManifest, wordProgress: Map<string, WordProgress>) {
  const ids = content.requiredWordIdsByStage[stageId]; // age6=155, age7=120, age8=120
  if (!ids.every(id => content.isPublishable(id))) return false;
  return ids.every(id => !!wordProgress.get(id)?.discoveredAt);
}

function canUnlockNextStage(
  previousStageId: StageId, map: MapProgress, content: ContentManifest,
  wordProgress: Map<string, WordProgress>
) {
  return isStageCollectionComplete(previousStageId, content, wordProgress)
    && map.gateMissionStatusByStage[previousStageId] === "completed";
}

function onQuizCardCorrect(card: QuizCard, activeStageId: StageId) {
  // 오답 재도전 후 최종 정답이면 카드 완료 1개.
  // 이미 수집한 고유 단어라면 수집 보상을 중복 지급하지 않는다.
  if (!progress[card.wordId].discoveredAt) collectSubjectOfWord(card.wordId);
  // 다른 단계 단어를 복습했다면 과거 단계 숙련 기록은 증가할 수 있지만,
  // 현재 단계 '새 수집 개수'를 증가시키지는 않는다.
}
```

**반드시 처리할 경계 조건**
- 새로운 콘텐츠를 업데이트해도 **이미 해금한 큰 맵/구역은 절대로 재잠금하지 않는다**. 앱 버전별 큰 맵 필수 콘텐츠 집합을 고정해 이미 완료한 졸업 기록을 유지한다.
- 6세의 원래 `wordId` 155개는 어떤 이유로도 일괄 재발급하지 않는다. `discoveredAt`가 있다면 기존 수집 캐릭터를 바로 표시한다.
- 콘텐츠가 15개만 구현돼 있을 때 15/15를 6세 맵 졸업으로 취급하지 않는다. **단계 필수 콘텐츠 목표는 항상 명시된 155/120/120개**다.
- `content_status=seed_only`인 항목은 실제 앱 플레이에서 제외하되, **맵 졸업 조건에서는 누락된 필수 자산으로 인식**한다. 출제 가능 개수와 학습 필수 총량을 서로 혼동하지 않는다.
- 7세 첫 구역만 처음부터, 다른 구역은 앞 구역의 16/20 수집 시 해제. 모든 7세 단어를 얻으려면 돌아가 덜 모은 단어도 수집해야 한다.
- 도감 상세에서 아무 단어나 눌러도 음성 재생 가능. 도감 듣기만으로는 수집·숙련 횟수를 올리지 않는다.
- 맵 이동 컷신은 **건너뛰기 가능**하며, 홈에서 이전 맵 다시 방문 가능하다.

## 19. '단어 그 자체'를 수집하는 캐릭터 설계

### 수집 방식(별도 몬스터를 만들지 않는다)

| 대상 유형 | 정답으로 얻는 것 | 도감 터치 시 반응 | 예시 |
|---|---|---|---|
| 동물 | 동물 자체의 캐릭터 | 고유 동작 + 영어 발음 | `cat` 고양이가 꼬리 흔들기, `fish` 물고기가 헤엄치기 |
| 음식·과일 | 해당 음식/과일 자체 | 가볍게 흔들림 + 영어 발음 | `apple` 사과 통통 튀기, `donut` 도넛 돌기 |
| 탈것·사물 | 해당 물건 자체 | 움직임 + 영어 발음 | `bus` 버스 출발, `rocket` 로켓 발사 |
| 직업·사람 | 그 직업인 본인 | 짧은 일하는 장면 + 영어 발음 | `firefighter` 소방관이 호스 들기 |
| 장소 | 장소 건물/작은 디오라마 | 작은 장면 애니메이션 + 발음 | `school` 학교, `hospital` 병원 |
| 행동·날씨·상태 | **단어 의미의 행동/상황 장면** | 행동·상태를 보여주는 2~4초 짧은 루프 | `run` 아이가 뛰기, `rainy` 빗방울 내리기 |
| 색·숫자·도형 | 그 색/수량/도형 자체 | 색상 반짝임, 수량 움직임 | `red` 빨간 칩, `eleven` 11개 구슬, `circle` 원 |

### 캐릭터별 4단계 도감 상태

1. **미발견:** 윤곽 실루엣. 다음에 만날 단어의 정답 글자/뜻을 미리 공개하지 않는다.
2. **수집:** 첫 정답을 맞히면 대상 자체가 컬러로 나타나 도감에 등록된다. 영어 발음 `Cat!` 등 한 번 재생.
3. **친해짐:** 다음 날에도 독립적으로 정답을 맞혀 캐릭터에 작은 별 장식을 달아준다.
4. **반짝 숙련:** 다른 날짜의 무힌트 자력 정답 조건을 충족하면 반짝 테두리 + 추가 자세/애니메이션을 해금한다. **새 캐릭터를 뽑는 보상이 아니라 기존 고양이/물고기 자체의 변화**다.

### 시각·음성 원칙

- 문제용 왼쪽 큰 그림과 도감 수집 캐릭터는 **동일한 개념·아트 ID**를 공유한다. 같은 단어가 문제에선 다른 캐릭터로 보이지 않게 한다.
- 영어 단어 음성은 `audio_word_asset`로 연결하고, 누를 때마다 **명확한 자연 발음**을 재생. 정답 후 `Cat! It's a cat!`처럼 단어+짧은 문장을 재생할 수 있게 구성한다. 실제 문장 파일은 원어민 검수 후 별도 제작.
- 자주 듣게 만들되 눌렀을 때 소리가 겹치거나 지연돼 불쾌하지 않게. 효과음은 음성보다 작게.
- 8세에서 `planet`, `orbit`, `galaxy`와 같이 장면 의미가 비슷해 보일 때는 구분되는 시각적 맥락 제작 전에는 **서로 오답 보기로 내지 않는다**.
- 초기 도감은 **동물/물체는 살아 움직이는 '그 대상'**으로, 추상·상황은 간결한 **행동 애니메이션 카드**로 구성. 이름이 없는 가공의 몬스터, 가챠, 랜덤 희귀도는 도입하지 않는다.

**전체 240개 신규 단어 및 한국어 뜻은 `wordlist-by-age.md`, 기계 판독 가능한 수집 사양은 `vocabulary.seed.json`을 사용한다.** `stages.seed.json`의 단어 수·구역 해금 규칙과 값이 일치해야 한다.

### 출제/성장 난이도

- **6세:** 단어 보기 3개, 그림+듣기 연결. 이미 아는 동물에서 시작.
- **7세:** 기본은 3개 보기. 익숙해지면 보기 4개 선택 가능. 같은 범주에서 정답 구별하되 애매한 그림 조합 금지.
- **8세:** 3~4개 보기 및 간헐적 '소리를 듣고 그림 선택' 형식 도입. `brush your teeth` 등 구/동사는 **정적인 사물 그림으로 출제하지 말고 장면**으로 제시.
- 모든 단계에서 **읽기 능력을 전제로 강제하지 않으며**, 오답이 난 단어는 소리를 들으며 반복하고 뒤에서 다시 정답을 맞혀야만 완료한다.

## 21. 데이터 파일, 마이그레이션 및 자동 검증

### 파일 역할

- `plan.md`: 기능·사용자 경험·개발 기준(이 문서).
- `vocabulary.seed.json`: 단계·구역·단어·한글 뜻(보호자만)·이미지/오디오 경로·수집 대상 정의 총 395개. 구체 리소스 바이너리 미포함.
- `stages.seed.json`: 큰 맵 3개, 하위 구역 총 22개, 100% 도감/80% 구역 해금/최종 20문제, 단계별 복습 비율 정의.
- `wordlist-by-age.md`: 새로운 7세 120개와 8세 120개의 전체 한국어 대조 목록.

### 기존 학습 기록 유지

1. 로컬 저장소의 기존 155개 `wordId`를 변경하지 않고 데이터 파일의 `stage_id="age6"`만 추가한다.
2. 기존 도감의 `discoveredAt` 및 숙련도 기록을 그대로 읽어 **해당 고양이/사과 등의 수집 캐릭터**를 복원한다.
3. 새 필드 `stage_id`, `zone_id`가 없는 저장 상태는 단어 ID의 새 콘텐츠 매핑을 사용해 보완한다. 정보가 없다는 이유로 모든 도감을 미발견으로 돌리지 않는다.
4. 이전 `Session`에 `stageId`가 없으면 `age6`으로 해석한다. 새 세션부터 `stageId`를 저장한다.
5. `schemaVersion`과 마이그레이션 테스트를 만들고, 중단→앱 종료→업데이트→이어하기 흐름을 검증한다.

### 구현 시 우선 실행할 자동 검사

- [ ] 전체 `words.length===395`, 각 단계 155/120/120, 7/8세 각 구역 정확히 20개 확인.
- [ ] `wordId` 유일성, `zone_id` 존재 여부, `collectible.id===wordId`, `collectible.subject_en===en` 확인.
- [ ] 신규 단어의 영어 표기가 기존 6세·서로 다른 신규 단계와 **중복되지 않는지** 확인. `orange`처럼 기존의 '과일/색' 의미 별도 항목은 허용하되 용례가 서로 혼동되지 않도록 검증.
- [ ] 30개 목표에서 2개를 여러 번 틀리더라도 **정답 카드 30개 완료 전까지 끝나지 않는지** 확인.
- [ ] 154/155 수집 중 7세 잠금, 155/155 수집만 완료해도 마지막 복습 전까지 7세 잠금, 마지막 복습 20/20 후 7세 해금.
- [ ] 7세 119/120 수집이면 8세 잠금. 120/120 + 20문제 미션 성공 후 열기.
- [ ] 7세 특정 구역 15/20이면 다음 구역 잠금, 16/20이면 다음 구역 해금.
- [ ] 모든 기존 단계·구역 잠금은 한 번 열리면 이후 복습 실패나 앱 업데이트로 되돌아가지 않는다.
- [ ] 7세/8세 현재 단계 새 단어 정답과 과거 단계 복습 정답을 별도로 집계한다.
- [ ] `content_status=seed_only`이며 이미지·영어 음성 실파일이 없는 단어는 출시 문제에 표시되지 않는다.
