# 헬로 아일랜드 (Hello Island)

그림을 보고 영어 소리를 들어 단어 친구 502명을 도감에 모으는 **아이패드용 영어 듣기 탐험 게임**.
6세부터 시작해 6세 → 7세 → 8세 세 개의 큰 지도를 차례로 엽니다.

**플레이:** https://ian939.github.io/hello-island/

## 어떻게 노나

1. **탐험 시작** → 섬 전체에서 서로 다른 단어 30개, 또는 **구역 타일**을 누르면 그 구역 단어 전부(10~30장).
   한 판에 같은 단어는 두 번 나오지 않는다 (틀린 카드만 다시). 복습할 때가 된 단어 → 못 만난 단어 → 나머지 순으로 뽑는다.
2. **새 친구 미리 만나기** — 이번 판의 처음 보는 단어 중 최대 5개를 그림과 함께 두 번(보통·천천히) 듣는다.
3. **듣고 고르기** — 왼쪽 그림을 보고, 오른쪽 영어 보기를 눌러 소리를 들어 본 뒤 `이거야!`.
   - 맞히면 기록판에 이름이 찍히고 단어를 듣는다. 처음 맞힌 단어는 **새 친구** 도장.
   - 이어서 **문장 팝업**: 그 단어가 들어간 아주 쉬운 문장(`The cat says meow.`)과 한글 해석이 뜨고 문장을 읽어 준다.
     영어 낱말마다 아래에 한글 읽기(더 캣 세즈 미아우)가 붙는다 (`tools/hangul.py`). `문장 듣기` 버튼은 80% 속도로 녹음한 문장.
   - **따라 말하기**: 마이크 버튼을 누르고 문장을 말하면, 자기 목소리를 한 번 들은 뒤 맞게 말한 낱말이 초록으로 표시된다.
     문장 낱말의 70% 이상을 순서대로 말하면 `다음`이 켜진다. 3번 해도 안 되면 "다음에 또 해 보자"와 함께 넘어간다 (막히지 않게).
     판정은 브라우저 음성 인식(아이패드 Safari 는 Apple 서버, 인터넷 필요). 마이크·인식을 못 쓰면 3초 뒤 `다음`으로 대신한다.
     보호자 화면에서 끌 수 있고, 최근 7일 통과율이 기록된다.
   - 틀리면 정답을 한 번 보여 주고 들려준 뒤, 그 카드는 4~7장 뒤에 다시 나온다. 모든 카드를 맞혀야 끝난다.
   - 같은 카드를 두 번 틀리면 보기가 하나 줄고, 세 번 틀리면 정답 칸이 빛난다.
4. 10장마다 별 조각 하나와 쉬어 가기. 중간에 그만둬도 남은 카드와 오답 순서가 그대로 저장된다.
5. 지도의 단어를 **모두** 모으면 최종 미션(서로 다른 20단어)이 열리고, 다 맞히면 다음 지도로.
   7·8세 지도의 구역은 앞 구역을 16/20 모으면 열린다.

**도감** — 모은 단어는 그 단어 자체(고양이는 고양이, 버스는 버스)가 캐릭터로 남는다. 눌러서 다시 듣기.
다른 날에도 혼자 맞히면 ★ 친해짐, 여러 날 맞히면 ✦ 반짝 숙련.

**보호자** (오른쪽 위, 덧셈 확인) — 첫 시도 정답률·재도전·자주 헷갈린 단어, 보기 3/4개,
느린 발음, 지도 직접 열기, 단어별 `이미 앎 / 제외`, 오프라인 내려받기, 백업·복원, 초기화.

## 만든 재료

| | |
|---|---|
| 단어·지도 | `tools/seed/` — 기획서(plan.md)·단어 395개·지도 22구역 원본(ID 그대로) + `tools/extra_words.py` — 6세 구역을 30개로 채운 107단어. 6세 262 · 7세 120 · 8세 120 = 502개 |
| 그림 | Microsoft [Fluent Emoji 3D](https://github.com/microsoft/fluentui-emoji) (MIT) 227개 + 맞는 이모지가 없는 126개는 Codex 이미지 생성으로 같은 화풍에 맞춰 그림. 색은 물감 방울, 숫자는 사과 개수, 도형은 SVG |
| 발음 | Microsoft Edge 신경망 음성 `en-US-AnaNeural` 로 미리 녹음한 mp3 (단어 · 느린 단어 · 팝업 문장 · 안내 1,199개) |
| 화면 | 빌드 없는 HTML/CSS/ES 모듈. 확대·복사 잠금(`js/lock.js`), 오프라인 PWA(`sw.js`) |

## 개발

```bash
python -m http.server 8000         # http://localhost:8000
npm test                           # 엔진 테스트 (node --test)

python tools/fetch_art.py          # Fluent 그림 받기
python tools/gen_art.py --plan     # Codex 로 그릴 판 목록 (9개씩 3×3 판 → 잘라 쓰기)
python tools/build_data.py         # seed + curation → data/words.json, data/stages.json
python tools/make_audio.py         # Edge TTS 녹음 (없는 파일만)
```

- 단어별 그림·헷갈림 묶음은 `tools/curation.py`, 정답 팝업 문장·한글 해석은 `tools/sentences.py` 에서 고친다.
  문장을 바꾸면 `assets/audio/x/<id>.mp3` 를 지우고 `make_audio.py` 를 다시 돌린다.
- 엔진(`js/engine/`)은 화면과 분리된 순수 함수다 — 카드 수·오답 재배치·해금 규칙은 `tests/` 로 검증한다.
- 6·7·8세는 게임 단계 이름이며 공인 연령별 필수 어휘표가 아니다.
